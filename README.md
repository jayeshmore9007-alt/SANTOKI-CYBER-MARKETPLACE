# SANTOKI CYBER MARKETPLACE

Cybersecurity and ethical-hacking hardware marketplace frontend starter.

## Run locally
1. Install Node.js 18 or newer.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open http://localhost:3000

## Included
- Responsive cyberpunk marketplace UI
- Cybersecurity hardware categories and sample products
- Product search and category filters
- Demo cart and wishlist
- Seller-interest and login modal prototypes

## Important: prototype only
This is a frontend starter with sample inventory. It does **not** yet include a production database, real user authentication, payment processing, order fulfilment, seller payouts, admin permissions, or a connected AI assistant. Cart and wishlist state reset on refresh.

## Production work required
- PostgreSQL/Supabase database and secure server-side product/order APIs
- Authentication, email verification and customer/seller/admin roles
- Seller KYC, product review and moderation
- Razorpay/other payment gateway with server-side order creation, signature verification and webhooks
- Inventory, shipping, returns, refunds and seller settlements
- Admin audit logs, rate limits, privacy policy and terms
- AI assistant through a protected server route; never expose API secrets in browser code

## Responsible-use policy
Only list legitimate defensive-security, education, electronics-lab and authorized-testing products. Exclude malware, credential theft, covert surveillance, illegal jamming and tools marketed for unauthorized access.
